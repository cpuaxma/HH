# Why Gold Rises When the Dollar Falls

A 33-second vertical reel (1080×1920, 60fps, 1980 frames) built in Remotion. One composition, `GoldDollar`, renders in English or Arabic depending on its `lang` prop.

## Render

```
npm install
npm run render            # both languages
npm run render:en         # out/gold-dollar-en.mp4
npm run render:ar         # out/gold-dollar-ar.mp4
npm run studio            # preview and scrub in the browser
```

Renders are H.264, CRF 18, yuv420p, frame by frame through `remotion render`. Fonts come from `@fontsource` packages and are bundled locally, so nothing is fetched at render time.

To use a Chrome or Chromium you already have instead of the one Remotion downloads, add `--browser-executable=/path/to/chrome`.

Stills for review (bundles once, renders both languages):

```
node scripts/stills.mjs <outDir> 90 325 655 985 1285 1585 1855
```

## Files

- `src/i18n.ts`: every string in both languages. `*word*` turns a word gold and `_word_` turns it dollar red. Each array entry is one line on screen.
- `src/theme.ts`: colours, easing curves, springs, text timing and the safe-area layout.
- `src/GoldDollar.tsx`: the scene `<Sequence>` frame ranges (`SCENES`), font loading, the CTA wipe, and the persistent wordmark.
- `src/scenes/`: one component per scene. Each scene's `T` object holds its local cue frames.
- `src/components/`: `AnimatedText` (per letter in English, per word in Arabic), `LightStreak`, `ChartLine`, `GoldBar`, `BackgroundGlow`, `Grain`, `MotionTrail`, `DiagonalWipe` and others.
- `src/data/map-dots.json`: the dotted world map, generated by `npm run dots` from world-atlas land-110m with d3-geo. Rerun it only to change the map.
- `public/logo.png`: the Miran Gold emblem, cropped to its gold circle with a transparent background.

## Rules the code follows

- **English** text animates per character, 1.5 frames apart, while the line's letter-spacing tightens from 0.35em to 0.
- **Arabic** text animates per word, 4 frames apart, right to left, and never has letter-spacing. It uses `dir="rtl"`, and any Latin token is wrapped in `<bdi>`.
- **Easing:** entrances use the expo-out curve `bezier(0.16, 1, 0.3, 1)` or a spring with `damping: 200`. Exits use cubic-in and run about 40% faster.
- **Safe areas:** nothing important sits below y=1600 or right of x=940. Content is centred between 140px gutters.
- **Ticker prices** in scene 4 are illustrative and are labelled that way on screen.
