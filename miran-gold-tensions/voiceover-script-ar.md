The Arabic voiceover for `out/gold-tensions-ar.mp4` (33 seconds), written for an AI voice. Each line matches the text on screen.

It's written to be read cleanly by text-to-speech:

- **Light tashkeel only.** Diacritics are added only where the AI could misread a word. For example, «الذَّهَب» stops it saying «الذَّهاب» (going). Full case endings on every word make AI voices sound stiff, like formal recitation, so they're left out.
- **No symbols or Latin text.** «XAU/USD», «٪» and numerals are never read aloud.
- **Commas and full stops mark the pauses.** There are no «…» or dashes, which AI voices handle inconsistently.

## Tips

- Generate each line as its own clip and drop it at its "Place at" time. Seven short clips are much easier to line up than one long take, and you can regenerate a single line if one word comes out wrong.
- If a word still sounds wrong, add a diacritic to just that word and regenerate that line. Don't add diacritics everywhere.
- **Brand name:** «جُولد» is marked so the AI says "jold/gold" rather than "jawlad". If you say the brand with a hard G, try a few spellings and keep the one that sounds right.
- Use the same voice and settings for all seven clips so the tone matches.
- The video has no audio. If you add music, keep it about 15–18 dB below the voice.
