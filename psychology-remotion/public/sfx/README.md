Optional sound effects. Each file is used only if it exists. Every cue frame, volume and a sourcing
note are in `../../sfx-cues.md` (generated from `src/config.ts`, `AUDIO`).

- `riser.mp3`: the climb (about 4.5 s, stops at the summit)
- `impact.mp3`: the crash, the drop, «ذعر», the buy/sell pins
- `heartbeat.mp3`: one "lub-dub"; triggered on every HUD heartbeat, so it follows the heart rate
- `alarm.mp3`: loopable alarm bed for the cold open and the panic
- `rewind.mp3`: tape stop + rewind
- `sub-drop.mp3`: hitting the bottom
- `piano.mp3`: one warm note at «أمل»
- `whoosh.mp3`: transitions
- `shine.mp3`: logo shine
